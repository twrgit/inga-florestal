# Logos dos parceiros

Originais consultados em https://drive.google.com/drive/folders/1_CxyRlCs5qi0VqNAjlJDAUB-ErZ2xmBX.

- Águas do Imperador, K2 e Pró-Mudas Rio: PNGs originais com canal alfa, sem alteração da marca.
- Consig e AFB: versões transparentes derivadas dos arquivos originais do Drive.
- Grupo Petrópolis: versão transparente derivada da referência do PSD; não há pasta desse parceiro no link fornecido.

As remoções de fundo usam a ferramenta integrada de edição de imagens. Prompt aplicado individualmente a cada marca:

> Remove only the flat off-white/white background and return a genuinely transparent PNG alpha background. Preserve the EXACT existing logo, lettering, spelling, colors, gradients, relative positions and proportions. Do not redesign or invent any symbols or text. Keep deliberate white details within the logo. Center the full logo with a small transparent margin. Clean sharp edges with no white/gray matte or halo. For low resolution input, enhance clarity conservatively without changing the design. This is asset cleanup, not new logo creation.

O CSS usa as cores próprias dos arquivos, sem modos de mistura.
